# Dossier des images

Dépose ici tes fichiers images (glisser-déposer via "Add file → Upload files"
sur GitHub, dans ce dossier `public/assets/`).

Noms de fichiers utilisés par le site (voir le README principal pour le détail) :

- `hero-bg.jpg` — bannière d'accueil de `pronostics.html`
- `logo.png` ou `logo.svg` — logo dans l'en-tête des pages joueur
- `avatar-default.png` — avatar par défaut sur `profil.html`

Tu peux aussi déposer d'autres images avec les noms de ton choix (ex:
`stadium-crowd.jpg`, `trophy.jpg`, `starball.jpg`) — dis-moi ensuite quel
fichier utiliser à quel endroit et je les branche.
